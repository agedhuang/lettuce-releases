# Lettuce

**⬇️ [Download Lettuce.dmg](https://github.com/agedhuang/lettuce-releases/releases/latest/download/Lettuce.dmg)**

Open it, drag **Lettuce** into Applications, launch it from there. The first launch shows macOS's standard "downloaded from the internet" prompt — click **Open**. Requires a Mac with Apple Silicon (M1 or later).

Full guide and release notes: **[Releases](https://github.com/agedhuang/lettuce-releases/releases/latest)**.

`latest.json` at the root of this repo is read by the app's built-in updater; do not move it.
