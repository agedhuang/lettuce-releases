# Lettuce — releases

Download the latest build from the **Releases** tab on the right.

- macOS on Apple Silicon (M1 or later). The app will not launch on an Intel Mac.
- Open the `.dmg`, drag **Lettuce** into Applications, launch it from there.
- The first launch shows the standard "downloaded from the internet" prompt — click Open.

`latest.json` at the root of this repo is read by the app's built-in updater; do not move it.

Found a bug? Use the feedback form linked in the release notes.
