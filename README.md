# Lettuce

**[⬇️ Download Lettuce.dmg](https://github.com/agedhuang/lettuce-releases/releases/latest/download/Lettuce.dmg)** — macOS, Apple Silicon (M1 or later).

Open the `.dmg`, drag **Lettuce** into Applications, launch it from there. The first launch shows the standard "downloaded from the internet" prompt — click Open.

`latest.json` at the root of this repo is read by the app's built-in updater; do not move it.
